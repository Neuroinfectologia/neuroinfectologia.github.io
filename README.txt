# LANI — Liga Acadêmica de Neuroinfectologia

Site oficial da Liga Acadêmica de Neuroinfectologia (LANI), vinculada à Universidade Christus.

## Sobre o projeto

O site apresenta a LANI, sua identidade visual e sua proposta de ampliar o olhar médico para as neuroinfecções, com foco nas infecções do Sistema Nervoso Central (SNC).

## Identidade visual

- Logo da Liga Acadêmica de Neuroinfectologia.
- Logo da Universidade Christus.
- Layout moderno em azul-marinho e ciano.
- Ilustração 3D do cérebro relacionada à neuroinfectologia.
- Design adaptável a computadores e dispositivos móveis.

## Tecnologias

- HTML5
- CSS3
- JavaScript (quando aplicável)

## Publicação

O site é hospedado pelo GitHub Pages:

https://neuroinfectologia.github.io/

## Como atualizar o site

1. Acesse o repositório do projeto no GitHub.
2. Edite ou substitua o arquivo `index.html`.
3. Envie os arquivos de imagem necessários, caso não estejam incorporados ao HTML.
4. Salve as alterações usando **Commit changes**.
5. Aguarde o GitHub Pages publicar a nova versão.

## Objetivo

Ampliar o olhar médico para as neuroinfecções e divulgar as atividades acadêmicas da LANI.

## Áreas de acervo adicionadas

O `index.html` agora inclui quatro áreas navegáveis: **Capacitações**, **Congressos e publicações**, **Livros** e **Ações de extensão**. Como nenhum material de acervo foi fornecido junto com o projeto, as páginas começam com estados vazios informativos — não há eventos, autores, livros ou ações fictícios.

### Como adicionar materiais posteriormente

- **Capacitações:** inclua o PDF autorizado no repositório e crie um card com título, data, palestrante/professor e link relativo para o arquivo.
- **Congressos e publicações:** adicione os registros com título, autores, evento/periódico, ano e links para resumo, certificado, artigo ou capítulo.
- **Livros:** informe título, autores, edição, ano, descrição e link de acesso legal. Use capas apenas quando houver autorização ou fonte apropriada.
- **Ações de extensão:** adicione data, local, instituições parceiras, objetivos, resultados, materiais educativos e fotografias com autorização de uso de imagem.

### Publicar no GitHub Pages

1. Faça upload do `index.html` atualizado e do `README.txt` no repositório, mantendo `LOGO LANI.png` e `hero-neuro.png`.
2. Faça commit na branch `main`.
3. Aguarde a atualização do GitHub Pages e teste o menu em computador e celular.
4. Ao adicionar PDFs ou imagens, mantenha-os em pastas organizadas (por exemplo, `arquivos/capacitacoes/`, `arquivos/publicacoes/` e `imagens/extensao/`) e use caminhos relativos nos links.

**Observação:** esta versão preserva o conteúdo e os recursos existentes no `index.html`; as quatro novas áreas foram acrescentadas ao final do conteúdo principal. O menu passa a abrir em formato recolhido em telas menores e também em larguras intermediárias, para acomodar os novos links.
